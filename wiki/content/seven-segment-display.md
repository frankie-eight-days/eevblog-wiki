A seven segment display is a numeric display element in which each digit is formed from seven individually addressable bars arranged around a figure-eight outline, almost always accompanied by an eighth element for the decimal point.<sup class="cite"><a href="#src-NvIv-0-R6qQ" title="Guest Video: TannerTech Designing a Frequency Counter">•</a></sup><sup class="cite"><a href="#src-400" title="EEVblog #400 - 400th Live Show">400</a></sup> It is the dominant way of showing numbers on instruments, clocks, calculators and controllers, because a digit costs only eight drive lines and needs no font tables, character generator or graphics memory in the driving [[processor]].<sup class="cite"><a href="#src-1241" title="EEVblog #1241 - Power Up Display Counter Project - Part 1">1241</a></sup> The same segment geometry has been realised in [[led|LED]], liquid crystal, vacuum fluorescent, neon planar and incandescent form, so "seven segment" describes a layout convention rather than any one display technology.<sup class="cite"><a href="#src-717" title="EEVblog #717 - How To Hack Vacuum Fluorescent Displays">717</a></sup><sup class="cite"><a href="#src-1044" title="EEVblog #1044 - LCD Technology Tutorial">1044</a></sup><sup class="cite"><a href="#src-ahoxDw0J2T8" title="Vintage Beckman Panaplex Planar Neon Display">•</a></sup><sup class="cite"><a href="#src-kSvB7hV0XU8" title="Space Time Continuum with Fran Blanche">•</a></sup>

## Structure and segment naming

In an LED seven segment device the package simply contains a number of discrete LEDs — eight of them once the decimal point is counted — each brought out to its own pin, with the remaining electrode tied in common.<sup class="cite"><a href="#src-NvIv-0-R6qQ" title="Guest Video: TannerTech Designing a Frequency Counter">•</a></sup> The segments are conventionally lettered A through G, and driver chips label their outputs to match so that pin A connects to segment A and so on.<sup class="cite"><a href="#src-NvIv-0-R6qQ" title="Guest Video: TannerTech Designing a Frequency Counter">•</a></sup> Where data is shifted serially into a display, the usual bit order is segment A through segment G with the decimal point last, and a mismatch between the order the pattern table is written in and the order the bits are actually clocked out is a standard source of garbled digits.<sup class="cite"><a href="#src-1531" title="EEVblog 1531 - Can ChatGPT generate all the code for my Macgyver Project? (Part 3)">1531</a></sup>

Two polarities exist. In a common [[cathode]] part all the cathodes are tied together and taken to [[ground]], so a logic one on a driver output turns its segment on.<sup class="cite"><a href="#src-801" title="EEVblog #801 - How To Design A Digital Clock">801</a></sup><sup class="cite"><a href="#src-1531" title="EEVblog 1531 - Can ChatGPT generate all the code for my Macgyver Project? (Part 3)">1531</a></sup> Common anode is the more widely encountered variant.<sup class="cite"><a href="#src-801" title="EEVblog #801 - How To Design A Digital Clock">801</a></sup> The distinction matters to software as much as to hardware: a segment pattern table written for common cathode drives its lamps with ones, and a default return of zero from a lookup function leaves every segment in that digit dark.<sup class="cite"><a href="#src-1531" title="EEVblog 1531 - Can ChatGPT generate all the code for my Macgyver Project? (Part 3)">1531</a></sup>

Individual segments are ordinary LEDs and need [[current-limiting|current limiting]] like any other. Applying a raw 9 V supply directly to a segment without a [[series-resistor|series resistor]] destroys it, leaving a display with one permanently dead bar.<sup class="cite"><a href="#src-s2KkgI-kyK0" title="The Signal Path Lab">•</a></sup>

## Decoding and driving

The classical approach converts binary-coded decimal into segment patterns in hardware. A 4511 is a BCD to seven segment decoder driver, fed from a BCD counter such as the 4518, and represents the traditional way of driving these displays.<sup class="cite"><a href="#src-801" title="EEVblog #801 - How To Design A Digital Clock">801</a></sup> The 4026 combines a decade counter with segment outputs in one 16-pin package compatible with common cathode displays, so a counter and its display need nothing between them.<sup class="cite"><a href="#src-801" title="EEVblog #801 - How To Design A Digital Clock">801</a></sup><sup class="cite"><a href="#src-NvIv-0-R6qQ" title="Guest Video: TannerTech Designing a Frequency Counter">•</a></sup> The MC4511 appears as the display driver in older bench multimeters.<sup class="cite"><a href="#src-482" title="EEVblog #482 - Retro Iskra Multimeter Teardown">482</a></sup> Where a converter chip presents its result as BCD rather than segment data — the ICL71C03 in a picoammeter, for instance, driving three and a half digits — a separate BCD to seven segment decoder must be added, usually on the front panel board.<sup class="cite"><a href="#src-406" title="EEVblog #406 - Keithley 480 Picoammeter Teardown &amp; Calibration">406</a></sup>

Decoding has also been done in mask [[rom|ROM]]: in one programmable calculator the segment patterns for the multiplexed display are held in ROMs acting as data to seven segment decoder lookup tables, a simple and effective method for the era.<sup class="cite"><a href="#src-1153" title="EEVblog #1153 - 1970&#x27;s Programmable Calculator Teardown">1153</a></sup>

Serial expansion is the common modern route. A 74HC164 eight-bit serial [[shift-register|shift register]] supplies exactly the eight outputs one digit plus its decimal point requires, and the parts cascade so that five digits become a single 40-bit shift register with 40 segment outputs.<sup class="cite"><a href="#src-1491" title="EEVblog 1491 - The MacGyver Project - Part 1">1491</a></sup><sup class="cite"><a href="#src-1531" title="EEVblog 1531 - Can ChatGPT generate all the code for my Macgyver Project? (Part 3)">1531</a></sup> A 595-type shift register with output latch is likewise suited to driving seven segment displays directly at modest currents, though not at 20 mA per LED.<sup class="cite"><a href="#src-1611" title="EEVblog 1611 - Top 5 Jellybean 7400 &amp; 4000 Logic">1611</a></sup> Dedicated peripherals exist at both ends of the scale: the Holtek 16K33 is an I²C LED driver intended for exactly this job,<sup class="cite"><a href="#src-851" title="EEVBlog #851 - Mailbag">851</a></sup> while the Intel 8279 is a combined keyboard and display controller that, with a 74LS156 decoder, runs the six-digit display of an 8085 design kit.<sup class="cite"><a href="#src-1308" title="EEVblog #1308 - 1970&#x27;s Intel MCS-85 8085 Design Kit!">1308</a></sup> Where segment [[current]] exceeds what the shift register can sink, high-side driver MOSFETs are added alongside a constant-current LED driver such as the TLC59282.<sup class="cite"><a href="#src-689" title="EEVblog #689 - Back To The Future Time Circuits Troubleshooting">689</a></sup> Indicator LEDs and seven segment digits are frequently combined into one multiplexed matrix driven through ULN2003 [[transistor]] arrays.<sup class="cite"><a href="#src-1360" title="EEVblog #1360 - REPAIR - Aircon Control Panel">1360</a></sup>

Driving straight from a [[microcontroller]] is also practical: eight port lines through series dropper resistors carry the seven segments plus the decimal point, and a further pin sinks the common cathode, since a typical micro can handle the roughly 30 mA involved.<sup class="cite"><a href="#src-400" title="EEVblog #400 - 400th Live Show">400</a></sup> A display enable line that blanks the digits is useful when the count is changing rapidly, so the observer sees only settled values rather than the intermediate counting.<sup class="cite"><a href="#src-NvIv-0-R6qQ" title="Guest Video: TannerTech Designing a Frequency Counter">•</a></sup> The same blanking technique hides data as it shifts through a chain of registers.<sup class="cite"><a href="#src-1531" title="EEVblog 1531 - Can ChatGPT generate all the code for my Macgyver Project? (Part 3)">1531</a></sup>

## Current, brightness and multiplexing

Segment current sets the whole power budget. At about 5 mA per segment — enough for decent brightness in a lab or office, let alone outdoors — a digit showing an eight with its decimal point lit draws eight times that, 40 mA for one digit.<sup class="cite"><a href="#src-298" title="EEVblog #298 - Dave&#x27;s Decade Digit Display - USB Supply Part 3">298</a></sup> Displays of this type therefore multiplex, holding total display current near the single-digit figure.<sup class="cite"><a href="#src-298" title="EEVblog #298 - Dave&#x27;s Decade Digit Display - USB Supply Part 3">298</a></sup> The current draw is significant enough to be a design driver in its own right: it is the reason LED seven segment displays get abandoned in favour of [[lcd|LCD]] in low-power products.<sup class="cite"><a href="#src-298" title="EEVblog #298 - Dave&#x27;s Decade Digit Display - USB Supply Part 3">298</a></sup><sup class="cite"><a href="#src-400" title="EEVblog #400 - 400th Live Show">400</a></sup> A mains energy-saving gadget consumed almost a watt purely to drive its seven segment displays.<sup class="cite"><a href="#src-1191" title="EEVblog #1191 - Digital Energy Savers BUSTED!">1191</a></sup>

[[multiplexing|Multiplexing]] divides the average current per segment by the number of digits in the scan. Sharing a 20 mA budget across 40 segments leaves half a milliamp each, which is far too dim to be useful, and pulse-width modulation cannot recover brightness that was never in the current budget.<sup class="cite"><a href="#src-1491" title="EEVblog 1491 - The MacGyver Project - Part 1">1491</a></sup> Outdoor-readable digits want on the order of at least 10 mA per segment.<sup class="cite"><a href="#src-1491" title="EEVblog 1491 - The MacGyver Project - Part 1">1491</a></sup> The scan must also be fast enough to [[fuse]]: each segment turning on at least 40 times per second is the threshold at which the flicker stops being visible.<sup class="cite"><a href="#src-1493" title="EEVblog 1493 - MacGyver Project - Part 2">1493</a></sup>

Where a multiplexed display shares one [[current-source|current source]] among segments, the source current is split between whichever segments are on, so brightness depends on how many are lit unless the drive compensates.<sup class="cite"><a href="#src-1493" title="EEVblog 1493 - MacGyver Project - Part 2">1493</a></sup> A conventional power-on self test lights all eights, then all decimal points, exercising every segment.<sup class="cite"><a href="#src-1493" title="EEVblog 1493 - MacGyver Project - Part 2">1493</a></sup>

## Liquid crystal seven segment displays

Segment LCDs are physically a glass sandwich of liquid crystal with at least one common pin — properly the backplane electrode — and one pin per segment.<sup class="cite"><a href="#src-1045" title="EEVblog #1045 - How To Drive an LCD">1045</a></sup> Unlike an LED display they cannot be driven with DC. The drive must be an AC [[waveform]] in which the polarity alternates between common and segment, which is why a dedicated [[lcd-driver|LCD driver]] is required rather than plain logic outputs.<sup class="cite"><a href="#src-1297" title="EEVblog #1297 - Turn an LCD into E-Paper!">1297</a></sup> Driving a segment LCD incorrectly with DC is a known way to damage it over time.<sup class="cite"><a href="#src-1297" title="EEVblog #1297 - Turn an LCD into E-Paper!">1297</a></sup> A microcontroller intended to drive bare seven segment LCD glass therefore needs LCD driving circuitry on board, and selecting one is a [[parametric-search|parametric search]] problem in its own right.<sup class="cite"><a href="#src-248" title="EEVblog #248 - LCD Enabled Microcontroller Selection">248</a></sup>

A display with few segments can be driven statically, with one common and no multiplexing, though the pin count rises accordingly — a static seven segment part may use two pins per segment, and even an old three and a half digit [[multimeter]] can be static if forty-odd pins are acceptable.<sup class="cite"><a href="#src-1044" title="EEVblog #1044 - LCD Technology Tutorial">1044</a></sup> Multiplexed glass requires calculating the discrimination ratio, the RMS voltages seen by on and off segments, and that arithmetic becomes involved for a seven-common panel; this complexity is the argument for using a dedicated LCD driver chip or a microcontroller with a built-in multi-segment multi-common driver.<sup class="cite"><a href="#src-1074" title="EEVblog #1074  - Custom LCD Design - Part 2 - (µSupply Part 17)">1074</a></sup> Inside the glass, the routing ties one digit's segments onto a common line, which is what makes the multiplexing possible.<sup class="cite"><a href="#src-1074" title="EEVblog #1074  - Custom LCD Design - Part 2 - (µSupply Part 17)">1074</a></sup>

## Designing custom segment glass

Custom LCDs are specified segment by segment. A µSupply panel came to 212 segments once its four-digit groups, decimal points, bar graph and annunciators were counted, which forced the choice of a driver with around 256 segment capability split into commons — in practice eight commons and 32 segment pins.<sup class="cite"><a href="#src-1055" title="EEVblog #1055 - How to Design a Custom LCD- µSupply Part 16">1055</a></sup><sup class="cite"><a href="#src-1105" title="EEVblog #1105 - $100 Custom LCD Design - Part 3 (µSupply Part 18)">1105</a></sup> Grouping matters: putting the eight segments that form one number on a single common lets the panel update that digit with one common drive, which is easier both in software and visually at refresh time.<sup class="cite"><a href="#src-1055" title="EEVblog #1055 - How to Design a Custom LCD- µSupply Part 16">1055</a></sup>

The segment artwork itself should be specified rather than delegated. If a manufacturer is simply told that six seven segment digits are wanted, it will use its own house font, which may produce segments that tilt, or that are thin and skinny, or short and fat.<sup class="cite"><a href="#src-1055" title="EEVblog #1055 - How to Design a Custom LCD- µSupply Part 16">1055</a></sup> Supplying the drawing gets the delivered glass as close as possible to the intended font, and it also allows the design to be moved between manufacturers later.<sup class="cite"><a href="#src-1055" title="EEVblog #1055 - How to Design a Custom LCD- µSupply Part 16">1055</a></sup> Custom seven segment glass is available with large digits and very good contrast, which is why it is attractive for instruments meant to be read from across a room.<sup class="cite"><a href="#src-1699" title="EEVblog 1699 - µTimer PROJECT Part 1 - The LCD">1699</a></sup>

## Alternative segment technologies

The seven segment layout is independent of the light-emitting mechanism. In a [[vacuum-fluorescent-display|vacuum fluorescent display]] the anode is a phosphor-coated conductive element that can be shaped into segments as readily as into dot matrix pixels or arbitrary artwork; a grid mesh at anode potential lets electrons through to make a segment glow, and pulling the grid to cathode potential turns it off.<sup class="cite"><a href="#src-717" title="EEVblog #717 - How To Hack Vacuum Fluorescent Displays">717</a></sup><sup class="cite"><a href="#src-1601" title="EEVblog 1601 - How VFD (Vacuum Fluorescent) Displays Work">1601</a></sup> A single seven segment VFD digit might be driven statically, but ten characters would be multiplexed as an LED display would be, and the high anode voltages rule out driving them from ordinary TTL or even 4000-series CMOS.<sup class="cite"><a href="#src-717" title="EEVblog #717 - How To Hack Vacuum Fluorescent Displays">717</a></sup>

Nixie tubes are not segmented at all: each digit is a separate electrode shaped like the whole numeral, stacked in front of one another, so they are driven from a one-of-ten decoder such as the obsolete 74141 rather than a segment decoder, and never have two outputs on at once.<sup class="cite"><a href="#src-948" title="EEVblog #948 - Nixie Tube Display Project - Part 1">948</a></sup> The Beckman SP351 Panaplex is a planar neon display carrying two seven segment digits.<sup class="cite"><a href="#src-ahoxDw0J2T8" title="Vintage Beckman Panaplex Planar Neon Display">•</a></sup> Incandescent seven segment displays were common in 1970s and 1980s equipment and appear throughout period films.<sup class="cite"><a href="#src-kSvB7hV0XU8" title="Space Time Continuum with Fran Blanche">•</a></sup>

E-ink is the notable gap. Segmented electronic paper would be ideal for a display that must hold a static reading without power, removing the need for any [[battery]] or [[supercapacitor]] backup, but seven segment e-ink modules have been discontinued and the technology is effectively all graphic now.<sup class="cite"><a href="#src-1241" title="EEVblog #1241 - Power Up Display Counter Project - Part 1">1241</a></sup><sup class="cite"><a href="#src-1242" title="EEVblog #1242 - Memory LCD+Supercaps+Low Power Design">1242</a></sup> A related discovery is that certain segment LCDs, after being abused with DC drive for a long period, begin holding their image with the power removed, behaving like e-paper.<sup class="cite"><a href="#src-1297" title="EEVblog #1297 - Turn an LCD into E-Paper!">1297</a></sup>

## Historical LED forms

Early LED seven segment dies were extremely small, so multi-digit parts were built with a lens over each digit — bubble displays — which makes the digits appear considerably larger than the die beneath.<sup class="cite"><a href="#src-561" title="EEVblog #561 - Mailbag">561</a></sup><sup class="cite"><a href="#src-618" title="EEVblog #618 - Mailbag">618</a></sup> Four-digit bubble packages of this kind were standard, and the format survives in vintage instruments.<sup class="cite"><a href="#src-618" title="EEVblog #618 - Mailbag">618</a></sup><sup class="cite"><a href="#src-1134" title="EEVblog #1134 - Dumpster Diving Teardown Tuesday">1134</a></sup> Displays recognisable as the modern traditional LED seven segment part date to around 1976, and unusual packages of the era include the very small Monsanto MV5080 and parts with staggered pin rows.<sup class="cite"><a href="#src-561" title="EEVblog #561 - Mailbag">561</a></sup>

Seven segment displays with hexadecimal keypads formed the entire user interface of early single-board computers, including a three-chip Z80 design where data was entered manually on DIP switches.<sup class="cite"><a href="#src-142" title="EEVblog #142 - Electronics Magazine Memories">142</a></sup><sup class="cite"><a href="#src-KKEYAdXEW-M" title="Dick Smith Kits">•</a></sup> Surface-mount LED seven segment displays have become uncommon enough to be worth remarking on when found in a teardown.<sup class="cite"><a href="#src-1263" title="EEVblog #1263 - Mailbag">1263</a></sup>

## Mechanical and product considerations

A discrete display behind a front panel needs a cutout, and getting those cutouts aligned is troublesome and adds manufacturing cost; a clear window over the whole front removes the constraint and leaves the display technology free to change.<sup class="cite"><a href="#src-298" title="EEVblog #298 - Dave&#x27;s Decade Digit Display - USB Supply Part 3">298</a></sup> Misalignment between faceplate and display is a visible symptom of low-cost construction.<sup class="cite"><a href="#src-315" title="EEVblog #315 - Korad KA3005P Review/FAIL">315</a></sup> Physical size is a deliberate choice — 0.5 in and 0.56 in LED digits are used where the display must be read at a distance.<sup class="cite"><a href="#src-400" title="EEVblog #400 - 400th Live Show">400</a></sup> The look is valued enough that graphical displays are sometimes drawn to imitate it, as on a lab supply whose readouts were made larger and given a seven segment appearance.<sup class="cite"><a href="#src-509" title="EEVblog #509 - Rigol DP832 Lab Power Supply">509</a></sup>

Seven segment rendering is a stock feature of instrumentation software too: the static I/O panel of a mixed-signal test instrument can be configured to display its digital outputs as a seven segment digit.<sup class="cite"><a href="#src-692" title="EEVblog #692 - Digilent Analog Discovery Review">692</a></sup><sup class="cite"><a href="#src-1552" title="EEVblog 1552 - Digilent Analog Discovery 3">1552</a></sup> [[schematic|Schematic]] capture libraries carry a good selection of seven segment symbols as generic parts.<sup class="cite"><a href="#src-253" title="EEVblog #253 - KiCAD Install &amp; Schematic - First Impressions">253</a></sup>

## Judgment on segment versus dot matrix

Where only numbers must be shown, the segment display is the better instrument display. Contrast on a seven segment panel is markedly better than on a full dot matrix of the same technology, and larger digits are easier to read for general use, at the cost of not being able to draw graphs or menus.<sup class="cite"><a href="#src-15" title="EEVblog #15 Part 1 of 2 - Fluke 189/289 multimeter review">15</a></sup> This preference is applied consistently in design decisions and in assessing other equipment: a [[soldering]] station with a seven segment readout is judged favourably against the alternative — "None of that dot matrix rubbish."<sup class="cite"><a href="#src-OvGdE5hC1Ro" title="Bakon BK212 Soldering Station - URGH">•</a></sup><sup class="cite"><a href="#src-1463" title="EEVblog 1463 - Mailbag">1463</a></sup> The counter-argument is capability, not legibility; dot matrix earns its place when logging, graphing and text are required.<sup class="cite"><a href="#src-15" title="EEVblog #15 Part 1 of 2 - Fluke 189/289 multimeter review">15</a></sup><sup class="cite"><a href="#src-e9cpKN69Avk" title="121GW Development History">•</a></sup>

Segment counts above seven exist for alphanumerics — 14-segment and starburst displays — and these consume the full output complement of a driver chip where a seven segment digit leaves pins spare.<sup class="cite"><a href="#src-689" title="EEVblog #689 - Back To The Future Time Circuits Troubleshooting">689</a></sup><sup class="cite"><a href="#src-1044" title="EEVblog #1044 - LCD Technology Tutorial">1044</a></sup><sup class="cite"><a href="#src-1602" title="EEVblog 1602 - Sony Amplifier REPAIR ADVENTURE">1602</a></sup>
