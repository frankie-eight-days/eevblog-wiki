Sample memory (also called acquisition memory or record length) is the high-speed buffer in a digital [[oscilloscope]] or [[logic-analyzer]] that stores the digitized samples of each acquisition. Its depth, specified in samples or points per channel, is a defining specification alongside [[bandwidth]] and [[sample-rate]], because it determines how long an instrument can record at full sample rate and how far a captured [[waveform]] can be zoomed before the underlying data runs out.<sup class="cite"><a href="#src-44" title="EEVblog #44 - Part 2 - Logic Analyzer Tutorial">44</a></sup><sup class="cite"><a href="#src-149" title="EEVblog #149 - Agilent Infiniivision 3000 X Series Oscilloscope Review">149</a></sup><sup class="cite"><a href="#src-1311" title="EEVblog #1311 - Can Your Oscilloscope Zoom OUT?">1311</a></sup><sup class="cite"><a href="#src-1260" title="EEVblog #1260 - $70 100MHz Oscilloscope?">1260</a></sup>

## Depth, time base, and sample rate

Capture duration is the product of [[memory-depth]] and sample interval, so once memory is exhausted the instrument must drop its sample rate as the [[time-base]] is slowed. A 4 meg point scope sampling at 5 GS/s falls to 2.5 GS/s and then 1.25 GS/s as the time base is wound out past 50 µs/div, because the memory cannot sustain 5 GS/s at 1 ms/div.<sup class="cite"><a href="#src-1311" title="EEVblog #1311 - Can Your Oscilloscope Zoom OUT?">1311</a></sup> Conversely, deep memory lets a user zoom from a wide capture down to fine detail such as individual [[spi]] data bytes, with the zoom range limited by the chosen memory depth.<sup class="cite"><a href="#src-199" title="Tektronix Mixed Domain Oscilloscope MDO4000 Review - EEVblog #199">199</a></sup> A scope that advertises 128k of storage depth but cannot zoom into a stopped waveform effectively wastes that memory.<sup class="cite"><a href="#src-1260" title="EEVblog #1260 - $70 100MHz Oscilloscope?">1260</a></sup>

Memory may be dedicated per channel or shared. The GW Instek GDS-1000B provides 10M per channel that is not shared<sup class="cite"><a href="#src-824" title="EEVblog #824 - GW Instek GDS-1000B Oscilloscope Teardown">824</a></sup>, while the Siglent SDS1104X-U has 14M points total that effectively shrink as channels are enabled<sup class="cite"><a href="#src-1355" title="EEVblog #1355 - NEW Siglent SDS1104X-U $399 4CH Oscilloscope Teardown">1355</a></sup>; the Rigol DS2000 captures 700 points across two channels at a fast time base and doubles to 1.4K when the second channel is turned off.<sup class="cite"><a href="#src-369" title="EEVblog #369 - Rigol DS2000 Oscilloscope Playing Around">369</a></sup> On the Tektronix MDO3000 one memory device serves two channels, so the sample rate halves when both are active.<sup class="cite"><a href="#src-587" title="EEVblog #587 - Tektronix MDO3000 Mixed Domain Oscilloscope Teardown">587</a></sup>

Instruments offer different memory management policies: automatic modes that maximize memory use for the [[current]] settings, fixed memory depth, or fixed sample rate; the Siglent SDS1000X HD drops the fixed-memory option entirely in favor of automatic management.<sup class="cite"><a href="#src-1311" title="EEVblog #1311 - Can Your Oscilloscope Zoom OUT?">1311</a></sup><sup class="cite"><a href="#src-1612" title="EEVblog 1612 - Siglent SDS1000X HD 12 bit Oscilloscope Teardown">1612</a></sup> Acquisition modes can also trade memory for speed — selecting maximum waveform rate on the Rohde & Schwarz HMO1202 drops the depth to 480k points.<sup class="cite"><a href="#src-842" title="EEVblog #842 - Rohde &amp; Schwarz HMO1202 Oscilloscope Teardown">842</a></sup>

## Waveform update rate

Deeper memory slows acquisition because more data must be processed and rendered per trigger. On the Tektronix MDO4000, measured update rate at one time base was roughly 3,000–4,000 waveforms per second at 1K through 100K points, fell to about 1,000 at 1M points, about 200 at 10M, and about 20 at 20M points; capturing a single event at 1M depth took on the order of 18 seconds.<sup class="cite"><a href="#src-199" title="Tektronix Mixed Domain Oscilloscope MDO4000 Review - EEVblog #199">199</a></sup> High advertised update rates can likewise depend on sacrificing memory: the Tektronix 4-series' 500,000 waveforms per second figure applies only in a special fast acquisition mode with drastically reduced sample memory, versus roughly 100 per second in normal mode.<sup class="cite"><a href="#src-1218" title="EEVblog #1218 - 1GHz Oscilloscope Spec Shootout">1218</a></sup>

## Displayed noise and aliasing

At a given time base, deeper memory preserves more high-[[frequency]] content, so a scope with more memory can display more apparent noise on an open input: the 1M point Rigol DS1052E shows more noise than an equivalent Tektronix purely because it captures more of it, and increasing memory depth on a scope visibly increases apparent noise.<sup class="cite"><a href="#src-601" title="EEVblog #601 - Why Digital Oscilloscopes Appear Noisy">601</a></sup><sup class="cite"><a href="#src-797" title="EEVblog #797 - Siglent SDS1000X Oscilloscope Review">797</a></sup> Too little memory at slow time bases also produces aliasing; a 20 MHz sine that aliases at a short depth displays correctly at 1M or 10M points.<sup class="cite"><a href="#src-199" title="Tektronix Mixed Domain Oscilloscope MDO4000 Review - EEVblog #199">199</a></sup>

## FFT analysis

Oscilloscope [[fft]] performance depends jointly on memory depth, sample rate, time base, and the number of FFT points; deep memory is of no use if the FFT engine cannot process that many points.<sup class="cite"><a href="#src-845" title="EEVblog #845 - Oscilloscope FFT Comparison">845</a></sup> Memory depth and FFT point count are distinct settings — a scope can capture at 1M points while the FFT uses far fewer.<sup class="cite"><a href="#src-1188" title="EEVblog #1188 - $10 DIY EMC Probe using Scope FFT">1188</a></sup> For fair cross-instrument FFT comparisons, both memory depth and sample rate should be matched, for example 1M points at 50 MS/s.<sup class="cite"><a href="#src-845" title="EEVblog #845 - Oscilloscope FFT Comparison">845</a></sup>

## Segmented and compression approaches

Segmented memory conserves depth by capturing only bursts of interest and skipping dead time, avoiding the need for hundreds of megabytes or gigabytes of continuous high-speed memory — a capability that otherwise commands $50,000–$100,000 instruments.<sup class="cite"><a href="#src-143" title="EEVblog #143 - Agilent 2000 X Series Infiniivision Oscilloscope Review">143</a></sup>

In logic analyzers, two memory systems exist: traditional sequential sampling, which stores a sample on every clock, and compression (transitional) sampling, which stores a word only when an input channel changes, time-stamping each transition — the same waveform may take four words instead of a thousand or a million.<sup class="cite"><a href="#src-44" title="EEVblog #44 - Part 2 - Logic Analyzer Tutorial">44</a></sup> Compression maximizes memory use for widely spaced packets, but it is not magic: any single fast-toggling channel forces a sample across all channels and can consume the whole buffer before a slow packet arrives, and compression analyzers with only a few kilobytes of memory lose packets once their transition budget is spent.<sup class="cite"><a href="#src-44" title="EEVblog #44 - Part 2 - Logic Analyzer Tutorial">44</a></sup><sup class="cite"><a href="#src-876" title="EEVblog #876 - NI VirtualBench Review">876</a></sup> The NI VirtualBench exposes this directly, letting the user specify a capture as 10,000 or one million transitions rather than a memory depth.<sup class="cite"><a href="#src-876" title="EEVblog #876 - NI VirtualBench Review">876</a></sup>

Streaming [[usb]] analyzers take the opposite approach: with no on-board buffer, they sample in real time to the PC, giving effectively infinite memory limited only by disk, but sample rates capped around 10–24 MS/s by USB bandwidth.<sup class="cite"><a href="#src-44" title="EEVblog #44 - Part 2 - Logic Analyzer Tutorial">44</a></sup><sup class="cite"><a href="#src-436" title="EEVblog #436 - Saleae USB Logic Analyser Review &amp; Teardown">436</a></sup><sup class="cite"><a href="#src-1018" title="EEVblog #1018 - ZeroPlus Logic Analysers">1018</a></sup> Analyzers with genuine on-board memory, such as the ZeroPlus range at 32K to 2M per channel with up to 8× sample compression, are not streamers.<sup class="cite"><a href="#src-1018" title="EEVblog #1018 - ZeroPlus Logic Analysers">1018</a></sup> Low-cost hybrid devices can be very shallow — the Digilent Analog Discovery logic analyzer uses only 2,048 samples with no compression.<sup class="cite"><a href="#src-692" title="EEVblog #692 - Digilent Analog Discovery Review">692</a></sup>

## Hardware implementation

Sample memory is implemented as dedicated devices adjacent to the acquisition [[fpga]] or [[asic]], identifiable by matched-length traces.<sup class="cite"><a href="#src-1038" title="EEVblog #1038 - Uni-T UPO2104CS Oscilloscope Teardown">1038</a></sup><sup class="cite"><a href="#src-587" title="EEVblog #587 - Tektronix MDO3000 Mixed Domain Oscilloscope Teardown">587</a></sup> Fast synchronous [[sram]] is common in mid-range scopes — ISSI 9Mbit parts in the HMO1202 and GDS-2000A, where two devices provide the 2M sample memory and a third supports the variable-intensity display and segmented memory<sup class="cite"><a href="#src-842" title="EEVblog #842 - Rohde &amp; Schwarz HMO1202 Oscilloscope Teardown">842</a></sup><sup class="cite"><a href="#src-475" title="EEVblog #475 - GW Instek GDS-2000A Oscilloscope Teardown">475</a></sup>; SRAM is preferred over DRAM for speed and ease of FPGA interfacing.<sup class="cite"><a href="#src-810" title="EEVblog #810 - Micsig MS310 Handheld Oscilloscope Teardown">810</a></sup><sup class="cite"><a href="#src-1018" title="EEVblog #1018 - ZeroPlus Logic Analysers">1018</a></sup> Higher-end designs use DRAM: the Rigol DS2000 pairs two 512Mbit parts for 64M per channel<sup class="cite"><a href="#src-360" title="EEVblog #360 - Rigol DS2000 Oscilloscope Teardown">360</a></sup>, the Uni-T UPO2104CS uses a single MT41K64 for its 32M per channel<sup class="cite"><a href="#src-1038" title="EEVblog #1038 - Uni-T UPO2104CS Oscilloscope Teardown">1038</a></sup>, and the Keysight HD3 uses a 512MB Micron device per channel to deliver 100M points.<sup class="cite"><a href="#src-1639" title="EEVblog 1639 - Keysight InfiniiVision HD3 Oscilloscope Teardown">1639</a></sup> Agilent/Keysight MegaZoom ASICs integrate the sample memory on-die, leaving no external memory around the acquisition chips.<sup class="cite"><a href="#src-144" title="EEVblog #144 - Agilent 2000 X Series Infiniivision Oscilloscope Teardown">144</a></sup><sup class="cite"><a href="#src-976" title="EEVblog #976 - Keysight 1000 X-Series Oscilloscope Teardown">976</a></sup>

Sample width matters: 8-bit scopes store one byte per sample<sup class="cite"><a href="#src-842" title="EEVblog #842 - Rohde &amp; Schwarz HMO1202 Oscilloscope Teardown">842</a></sup><sup class="cite"><a href="#src-1038" title="EEVblog #1038 - Uni-T UPO2104CS Oscilloscope Teardown">1038</a></sup><sup class="cite"><a href="#src-1477" title="EEVblog 1477 - TEARDOWN! - NEW Tektronix 2 Series Oscilloscope">1477</a></sup>, while a 12-bit converter such as the R&S MXO4's requires at least two bytes per sample from its 8Gbit memory devices.<sup class="cite"><a href="#src-1545" title="EEVblog 1545 - R&amp;S MXO4 TEARDOWN. The World&#x27;s Fastest Oscilloscope!">1545</a></sup> Installed memory can exceed the marketed depth — the Tektronix 2 Series carries four 512MB devices (two gigasamples of hardware) for a specified 10M point depth.<sup class="cite"><a href="#src-1477" title="EEVblog 1477 - TEARDOWN! - NEW Tektronix 2 Series Oscilloscope">1477</a></sup>

## Capacity in context

Expectations have shifted by orders of magnitude. Early digital scopes ran on kilobyte-scale buffers — 1K points on a 25 MS/s Kikusui<sup class="cite"><a href="#src-1716" title="EEVblog 1716 - University Dumpster Diving: Kikusui Oscilloscope">1716</a></sup>, 2K SRAMs in the Fluke Combiscope<sup class="cite"><a href="#src-1450" title="EEVblog 1450- $99 Fluke Combiscope Ebay SCORE!">1450</a></sup>, 2K per channel in the Hameg hybrid<sup class="cite"><a href="#src-502" title="EEVblog #502 - $19 Hameg Analog Oscilloscope">502</a></sup> — and the Tektronix TDS2024C shipped with the same 2.5K depth as its 1997 ancestor, barely a couple of screens' worth.<sup class="cite"><a href="#src-187" title="EEVblog #187 - Tektronix TDS2024C Oscilloscope Teardown">187</a></sup> Eight megabytes was massive for a 1999 Tektronix TDS540D<sup class="cite"><a href="#src-1185" title="EEVblog #1185 - Dumpster Tek 500MHz TDS540D Scope">1185</a></sup>, LeCroy built its reputation on huge memories with fast acquisition<sup class="cite"><a href="#src-217" title="EEVblog #217 - Lecroy 9384C Oscilloscope Teardown">217</a></sup>, and the Agilent 90000 series reached one gigabyte of high-speed sample memory.<sup class="cite"><a href="#src-342" title="EEVblog #342 - Agilent 90000 Oscilloscope Teardown">342</a></sup> Modern mid-range instruments run from 14M<sup class="cite"><a href="#src-1042" title="EEVblog #1042 - Siglent&#x27;s $499 SDS1104X-E 4CH Oscilloscope Teardown">1042</a></sup> and 32M<sup class="cite"><a href="#src-1038" title="EEVblog #1038 - Uni-T UPO2104CS Oscilloscope Teardown">1038</a></sup> to 200M points<sup class="cite"><a href="#src-1309" title="EEVblog #1309 - Siglent SDS2000X Plus Scope Teardown+Hack">1309</a></sup>, with the Rigol 7000 expandable to 500M<sup class="cite"><a href="#src-CMoBGGqojqs" title="Rigol MSO7000 Unboxing &amp; First Impressions">•</a></sup>. Memory is also divided between pre- and post-trigger data, with the trigger point determining the split.<sup class="cite"><a href="#src-290" title="EEVblog #290 - Mailbag">290</a></sup><sup class="cite"><a href="#src-1716" title="EEVblog 1716 - University Dumpster Diving: Kikusui Oscilloscope">1716</a></sup>

## Multimeter data logging

Handheld and bench multimeters use sample memory for [[data-logging]]. The Agilent U1272A stores 10,000 points with auto and trigger-hold modes that append each probed reading, though its manual hand-logging mode is inexplicably limited to 100 samples.<sup class="cite"><a href="#src-216" title="EEVblog #216 - Gaussian Resistor Redux">216</a></sup><sup class="cite"><a href="#src-249" title="EEVblog #249 - Agilent U1272A Multimeter Review">249</a></sup> The Keysight U1282A's trig hold similarly appends readings to sample memory on probe contact.<sup class="cite"><a href="#src-832" title="EEVblog #832 - Keysight U1282A Multimeter Teardown">832</a></sup>
