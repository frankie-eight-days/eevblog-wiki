# sd card

The SD card is the default removable storage medium in modern consumer and bench electronics, serving three distinct roles that are often confused with each other: bulk data storage for captured media, a transfer medium for firmware images, and the boot device holding an instrument's entire operating system.[1679][1717][96XE5Ye1q6I] Its ubiquity and near-zero cost mean that adding a socket to a design is one of the cheapest expansions available, which makes its omission from a product a deliberate decision rather than a cost-driven one.[322][121] For test equipment in particular, an SD slot changes the architecture of the product, not just its feature list.[184]

## Why an instrument designer chooses SD over USB

In a mains-referenced or floating measurement instrument, a USB port is not free: a USB input terminal requires isolation, which is awkward and expensive to implement.[184] An SD card negates the need for the isolated USB interface entirely, because the card is physically removed and read elsewhere, and it simultaneously provides standalone logging and a firmware upgrade path.[184] The same reasoning was carried into the 121GW multimeter, where the SD card became a major feature and displaced the original plan of re-flashing firmware through an in-circuit programming header with a PICkit.[e9cpKN69Avk] A meter that requires a programmer to update is a meter most owners will never update; one that takes a file on a card can be updated by anyone.[121]

The card also buys development flexibility. In the Uni-T arbitrary waveform generator, the entire operating system lives on an SD card, which makes both development and field firmware updates straightforward, at the cost of a socket, ribbon cabling and connectors that a design shaving every cent would not carry.[1679] Rigol adopted the same approach: the DHO800 and the 350 MHz 1717-series scopes both boot their Android-based systems from a card on the main board, a micro SD in the latter case, in both cases hidden — one glued down, one covered with tape.[1563][1717] Removing the card from the DHO800 stops the boot process entirely, with no splash message at all, confirming the card holds material required for boot rather than incidental data.[1563]

## Firmware update as a recovery path

Because the card is read before the main application runs, it provides a route back from a bricked instrument. A Siglent signal generator shipped with pre-release firmware that failed was recovered through the micro SD card on the board: the card is formatted FAT32, the supplied files copied to it, the card inserted, and the unit powered up with a link shorted to force the bootloader.[tM2j9zuBiRQ] A dedicated formatting utility was not required in practice; an already-FAT32 micro SD card worked directly, and the utility itself returned a write-protected error.[tM2j9zuBiRQ] The FLIR TG165 exposes the same mechanism explicitly: holding the down arrow while powering on brings up an upgrade-firmware and initialize-SD-card mode, which simply refuses to proceed when the firmware file is absent.[669]

On the 121GW the procedure is a plain file copy — a .bin file placed in the root directory of the card — followed by holding the hold and memory buttons while switching on, then pressing setup to start the download.[96XE5Ye1q6I] A bootloader-based update of this kind is expected to be robust against the card being pulled mid-write, although that failure mode was never deliberately provoked.[96XE5Ye1q6I] Cards suitable for the job cost almost nothing: the meter shipped with an 8 GB card, and 2 GB cards of the kind used were regarded as effectively disposable.[1051][121]

## Logging

Standalone logging is the other half of the argument for SD in instruments. A thermocouple datalogger writing CSV directly to the card, powered from micro USB, needs no host computer for logging runs spanning a month or more, and creates its log file automatically when the record button is pressed.[872] The same pattern recurs across bench gear: a class 1 sound level meter carries an SD slot specifically because it can data log, alongside LAN, USB and an internal rechargeable battery,[1745] and a femtoammeter saves its log data to card in what appears to be CSV.[1755] Logging duration in the 121GW is limited by the batteries rather than by the card — testing produced figures in the range of 350 to 400 hours of non-continuous logging, and there is no practical upper limit on card size that a user will reach before the batteries expire.[ILIO5b1BliE][121]

## Speed, class and throughput

Card speed is a real system parameter, not a marketing tier. Replacing a class 1 card with a class 3 (A2) card in a Rigol MHO 980 series scope cut boot time from about a minute and twelve seconds to 57 seconds, though the boot time is variable enough that the improvement is better described as roughly ten seconds than as a fixed figure.[Fx3YixoQS6E] The DHO800 boots in the 45 to 47 second range from its glued-in 32 GB card.[1563]

At the other end, an SD card can be too slow for the acquisition rate it is asked to serve. A high-speed camera records continuously into a DDR3 memory buffer and only writes to the card after the trigger stops the capture, because the card cannot keep up with live capture; saving several thousand frames from the buffer then takes minutes.[947] Marking in and out points before saving avoids writing redundant data and saves substantial time on the write-back.[947] In a 3D printer controller the bottleneck is upstream of the card: parsing ASCII G-code and converting it to integers and floats is a large speed hit, and because the SPI port is deliberately run below full speed for reliability, the controller can barely keep up with the card's data rate.[843]

## The video production workflow

An SD card is a physical transport medium when a network is not fast enough. With no practical way to move HD footage between the lab and the editing machine over a network, the card is taken out of the camera at the end of a shoot, carried in a pocket, and read at the other end — a workflow chosen deliberately over copying files, and one that predates and outlasted the alternatives considered, including a second pocket hard drive for transport.[500][943] For single-take material the footage goes from card to upload with no editing or transcoding at all;[943] for edited material, clips are dragged from the card into the timeline in shooting order, which is why the shooting is done in sequence in the first place.[cPuMgh-BElU] Raw files were formerly copied from the card straight onto a NAS array and edited from there, a step now preceded by transcoding H.264 to H.265 for a significant file size saving.[cm1HFKOOCgo]

The consequence of a card-based workflow is that a card-related mistake costs a day's shooting: hours of footage have been lost to SD file format handling, on more than one camera brand, requiring the entire session to be reshot.[731] Card slots on host machines are valued accordingly — a top-mounted fast SD slot on a PC case is a deciding purchase factor for someone carrying cards daily, and an SD slot on a mini PC or laptop is called out as directly useful for the same reason.[462][eWbOLKaeBtU][1695]

## Cameras and consumer expandability

Dual card slots enable relay recording, where recording switches automatically to the second card when the first fills, which is useful for long recordings and time-lapse.[650][2] Dual slots appeared on bottom-of-the-range consumer camcorders while remaining a professional feature elsewhere, sometimes on a dedicated board carrying nothing but the two sockets and a few bypass capacitors.[454]

Absence of a slot is treated as a design failure where storage matters and as a non-issue where it does not. Omitting SD expansion from a tablet is inexcusable given that the socket and a slit in the case would have cost nothing, and points to a deliberate decision such as upselling cloud services.[322] The same tablet's file browser nonetheless presents a path labelled SD card 0 on a device with no SD card at all.[322] By contrast, an e-reader without audio capability has little to store, so the lack of a slot matters little; on a version with audio, which consumes storage quickly, the expansion becomes necessary.[205] Where a slot is present on a device of reasonable physical size, full-size SD is preferable to micro SD — the smaller format earns its place in phones, not in products with room for the larger card.[188]

## Physical integration

The card socket is a mechanical constraint as much as an electrical one. In a compact camera the SD assembly required a cutout in the board because even a 0.8 mm board was too thick for the profile available, forcing a two-board arrangement joined by ribbon cables.[1428] In an action camera the heat sink is routed through the entire body and out to the card, with a cutout for it, packing every dimension of the available space.[399] Cards mounted directly on the board sit among high-speed parallel buses and crystal oscillators, which is why that region ends up under copper shielding.[271] Poorly considered integration is equally visible: a tripod mount that blocks access to the battery compartment and the card while a tripod is attached is a known failure of consumer design, and one not confined to cheap brands.[595] Small documentation failures matter too — an unlabelled slot on a printer's side panel leaves the user guessing what goes in it and which way up.[318][327]

## Failure modes

Cards and card systems fail in characteristic ways. An OS card recovered from an instrument may be unreadable on a host machine under both Windows and Linux readers, leaving its contents unknown even when the instrument boots from it.[1563] Camera cards can similarly refuse to yield anything readable on a PC, with the stored file likely being a raw format rather than JPEG.[1619] A high-speed camera has returned a save directory is not writable error, cleared by removing the card and reinserting it.[947] A card can also simply die in the field, taking a shoot with it.[Ns0i3PEfOag] A card that becomes unformattable — sitting and spinning its wheels indefinitely — is beyond software recovery and, in at least one case, was disposed of with a hammer.[3lOXgwUAqR4]

## Predecessors and marketing

SD replaced a lineage of removable media that seemed unremarkable at the time: 3.5 inch floppy disks in the first consumer digital cameras, chosen around 1994 because SD did not exist until roughly 2000 and Memory Stick was a year away, and because floppy readers were universal while compact flash readers for PCs were not;[625][624] and PCMCIA cards in the first DSLRs.[495] Compact consumer film cameras of the mid-1990s, of course, had no card at all.[1440]

The format has also attracted marketing that has no engineering basis. A premium-priced memory card silk screened with "premium sound" and sold on the claim of lower noise is an ordinary SD card, and presenting it as anything else is an insult to the engineers who worked on it and to engineering and scientific progress generally.[719]

## Embedded and single-board use

For single-board computers the card is the system disk: an operating system image is downloaded, written to the card, and booted directly, which is how a Raspberry Pi distribution with a pre-installed FPGA toolchain is delivered.[618][8OaZ89TN0fo] Distributing a full pre-built image this way has a maintenance cost, since the image drifts behind the upstream distribution within months; starting from a stock image and installing the toolchain separately avoids that.[8OaZ89TN0fo] Cards supplied with a board are typically preloaded, but a supplied card that has sat for a month or two is a plausible suspect when the system misbehaves, and reflashing from a freshly downloaded image is the first thing to try.[2][858]

At the microcontroller level the card is cheap mass storage behind SPI, requiring a FAT file system implementation, which is a genuine burden in a small system.[843][900] Vendor stacks now supply it: FAT file system middleware appears as a configuration option alongside an RTOS in ST's configuration tool, and FAT-on-SD is a standard application note alongside Ethernet and AES.[900][269] Once available, the card underpins bootloaders that load firmware images from removable media, the same pattern used in commercial instruments.[900]
