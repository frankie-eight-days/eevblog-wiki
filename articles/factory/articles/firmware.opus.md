# firmware

Firmware is the code that runs inside an embedded product's microcontroller or processor, as distinct from the PC-side application software that may talk to it. In modern test and measurement gear it is where most of the product's behaviour actually lives: the analogue front end and the precision parts set the limits, but the measurement modes, the user interface, the protection logic and the calibration handling are all code.[1550][1463] The consequence is that two units with identical hardware can be different products, that a hardware fault and a firmware fault can look the same on the bench, and that a fix — or a new feature — can arrive as a download.

## Firmware as the product

In a Keysight battery emulator the local processor handles overcurrent and overvoltage protection, ESR emulation, constant-power and constant-current modes; the block diagram itself is fairly simple, and "All the magic's in the firmware" and in the precision parts.[1550] The same division shows up in an electric fence controller, where the pulse shaping, transformer design and cap charge-discharge cycles are supported by a large amount of intelligence in the firmware.[1292] A JBC soldering station carries enough code to drive a dot-matrix LCD with its own font set over USB-updatable firmware, which is a great deal more code to lock up than a basic iron running an analogue control loop.[472] There is a defensible engineering position that a soldering iron does not need firmware at all.[400]

Firmware also determines characteristics that appear purely electrical. On a Brymen BM786, older firmware switched the continuity beeper on at around 270 to 280 ohms and needed hysteresis out to about 300 ohms to release; revised firmware moved the threshold to just under 40 ohms with release at 100 ohms, and changed the pulse stretching so the buzzer went from strongly latching to intermittent.[PSdF0KNsiaY] On the BM2257, the only significant difference between release 2503 and the later 2506 is the continuity tone frequency.[lZYvGxQttT4][1745] On the 121GW, successive releases attacked ohms auto-ranging speed: 1.04 improved it, 1.05 improved it again, and version 2.00 changed the update rate on high-resistance readings.[uUCQuIp_hzU][q4gXnpFPFzQ] A smart meter's residual temperature coefficient — of the order of half a degree of error over a 50 °C span — is a candidate for firmware compensation using an ambient measurement rather than a hardware change.[409]

Firmware equally governs power consumption. Phone firmware revisions repeatedly improved standby current on a Nokia handset, which makes power a first-order design concern for embedded programmers rather than an afterthought.[80] Measuring a product's consumption profile can require modifying the product's own firmware so that its mode changes are synchronised with the capture instrument's trigger.[1331]

## Field-updatable versus burned-in

A sealed, non-upgradable firmware image can be relied upon absolutely; an upgradable one raises the question of what latent defects it is expected to fix. As instrument complexity grows — data logging in a handheld multimeter increases software complexity by roughly an order of magnitude — field upgrade becomes the reasonable choice.[15]

At the low end the choice is made by the silicon. A multimeter chipset with 6K words of one-time-programmable program memory and 256 bytes of data memory cannot be reflashed: a bug fix means scrapping programmed stock or shipping the old code, because only blank parts can be programmed.[912] A socket tester's die is programmed after board assembly via pogo pins, which permits bug fixes at the production stage but never by the user.[1598] Some Brymen meters are reprogrammable only through a header inside the battery compartment, using a programmer released under NDA to dealers.[JI4b-7vpIDc][mkZFHEeQkQI] Calibration constants can survive this: on a BM786 they live in the protected region of the micro rather than an external EEPROM, so a firmware update preserves them while physically replacing the chip does not.[1520]

Deliberately unupdatable firmware is sometimes a security decision. A card-format hardware wallet has closed-source firmware that cannot be updated at all, which removes an attack surface at the cost of any later fix and of independent verification.[dSek3p8gyv4]

## Update mechanisms

The common paths are a USB mass-storage stick read by the instrument,[209] a microSD card prepared on a PC — the recovery route for a signal generator shipped with pre-release firmware that failed to boot,[tM2j9zuBiRQ] a vendor utility that downloads and pushes the image,[1608][1056] a network fetch initiated from the device's own setup menu,[1151] and DFU — Device Firmware Upgrade — over USB using a bootloader already present in the part, as ST parts ship pre-programmed with one.[1306][1264][633] The most frictionless variant enumerates as a drive so the hex file is simply dragged into a directory and the device renamed and reflashed it on the next power cycle.[1335] Bluetooth modules can be updated over the air from the phone app.[XOuYJ1nxVJQ][Q_RYG_5cQk8]

Multi-board instruments complicate this. A USB oscilloscope carries separate ADC-board and controller firmware in different directories, and its updater failed to locate the image at all when run from the packaged distribution rather than from the Python source tree, because the relative path assumed a different depth.[1709] A bench scope's logic analyser pod and function generator each carry their own firmware version separate from the scope firmware.[474] Pods can be locked to the host by a serial EEPROM whose ID tells the firmware which module is plugged in, so a third-party pod would also have to reproduce that firmware.[475] Plug-in gas sensor modules use the same identifier trick to self-configure and recalibrate on insertion.[603]

## Failure, lockup and recovery

Firmware defects in instruments are common enough to be a standard suspect. A scope that stops responding entirely to front-panel input is obviously firmware, and lockups in test gear are not excused by a low price.[487] Documented cases include horizontal-mode freezing,[441] time-base anomalies on a bench scope,[797] a battery-gauge bug in a high-speed camera,[947] and a multimeter that produced a spurious insertion error when the rotary switch passed through Off quickly.[d5CxW3VBoZU] A camcorder that continued to display a running record counter while writing nothing, because the SD card had been removed, is a firmware failure regardless of what the manual says — the correct behaviour is a warning or a lockout.[2]

Diagnostic firmware is frequently the missing piece. An intercom that fails its EEPROM access and then simply does nothing illustrates the point: well-designed firmware initialises the display first and then reports a fault code when a checksum or read-write test fails.[710]

Firmware can also be destroyed in the field. A Fluke 87V could be bricked outright, its firmware erased, by a nearby GSM handset — near-field EM radiation on the LCD side would at minimum lock the meter up.[185][112][EJ6KCpHc--4] Locked-up firmware in a returned multimeter was cleared by reprogramming through the internal header, with nothing physically wrong with the unit.[mkZFHEeQkQI] A bricked 3D printer controller can resist recovery for reasons that have nothing to do with the target — AVR programmer, driver and toolchain problems rather than the hex file itself.[500][274]

Vendor turnaround varies. A multimeter fault traced to firmware was investigated, acknowledged and fixed with a downloadable update within three weeks.[178] An oscilloscope's sample-clock jitter attracted a beta firmware fix released for public trial before general release; that build did not fix the problem and introduced keyboard lockups, and was withdrawn before a working release followed.[699]

## Feature gating

Because features are code, the same hardware is routinely sold at several price points with firmware as the differentiator. Module keys for a mixed-domain scope contain only a serial code that enables firmware already built into the instrument, an approach with the practical weakness that the physical keys can be stolen — a software licence key is preferable.[199] A scope's 50 ohm input path may be physically present with 800 MHz of bandwidth while the software refuses to enable it.[1510] A Fluke 77 IV shares enough hardware with a 179 that temperature measurement is plausibly already present, with the firmware being what is actually paid for.[1448] Model identity itself can be soft: sending a serial command to change the reported model number causes the firmware to switch a 50 MHz scope into 100 MHz mode, and the underlying control lines can also be tied in hardware, so the mod survives a firmware countermeasure unless the board changes too.[70]

Gating also works in the user's favour. Firmware can disable autoscale on a teaching bench so students cannot use it while the instructor's back is turned.[143] A version 2.0 release added arbitrary waveform capability to an existing scope's waveform generator option as a free download.[209] Shared firmware across a product line is a deliberate economy: a scope's UI is built to scale so the same image serves a 1,024 by 600 panel and the higher-resolution screens of upmarket models,[1563] and a 7.5-digit meter derived from an existing platform needed only minimal firmware change with a team of four rather than twelve.[1032]

## Reverse engineering and modification

Firmware is a target. A 121GW user decompiled the binary, located the auto-ranging code and produced a modified image that measurably improved ohms range speed, closing most of the gap to reference-grade meters.[3MD88EYLdQQ] A pocket oscilloscope hobbled by its stock code was a candidate for rehabilitation by completely reverse-engineered replacement firmware.[1260] An ARM dev board's firmware was rewritten from scratch after being reverse engineered, allowing arbitrary transmit frequencies.[1207] A discontinued speaker was freed from its vendor's software by replacing the board entirely, rather than being discarded for firmware incompatibility.[1519][1514]

Such attempts fail as often as they succeed. An 8.5-digit variant of a bench meter differs from the 7.5-digit model mainly in its voltage reference, suggesting a firmware-limited resolution; a ROM dump revealed no model-number string to flip and would require full disassembly of the 65C02 binary.[615] A spectrum analyser board carries unpopulated footprints for an extra IF band-pass filter that an existing digital switch could select, which a software option in the firmware might still be able to enable.[1109] A thermal imager's Lepton sensor could in principle give absolute values under rewritten firmware, but without a calibration shutter the result would not be useful.[669] Where the acquisition path is FPGA rather than ASIC, there is no fundamental obstacle to changing a behaviour in firmware or in the reconfigurable fabric itself.[1311]

## Security firmware

In hardware wallets the firmware is the security boundary. Signed firmware verified against a vendor private key means tampering erases the stored keys, so a programmer attached to the debug header yields nothing.[1006] A power-analysis side channel that recovered a private key was subsequently closed in firmware, leaving only ordinary periodic display-update and loop activity visible in the current trace.[1006] One device ships with no firmware at all and requires the user to install it before first use.[uOOGXORqsqQ] Where a secure element is used, its firmware may be closed even when the application and interface are open source, and the device relies on a per-unit secure ID rather than a firmware self-checksum to prove authenticity.[1048] Open firmware permits community verification but is not the whole defence.[1048]

Firmware can also be used to obscure. A safe lock's power signature was not exactly repeatable between identical entry attempts, consistent with deliberate randomisation in firmware to frustrate power-line attacks — a defence a well-designed product would be expected to include.[771] Conversely, firmware protection is a legitimate way to protect a design from copying: putting the functionality in a microcontroller and blowing the read-protect fuses makes reverse engineering difficult enough that copying the whole idea from scratch becomes the easier path.[106]

## Development and quality

Firmware quality means working reliably and meeting the stated requirements, and the scarce skill in industry is the engineer who understands both the software and the hardware.[818] Normalising devices that misbehave until power-cycled is a failure of that standard.[818] Getting embedded behaviour right can take many iterations — a single capacitive touch button on one consumer product went through 56 firmware versions.[1211]

Firmware is one of the disciplines a full product design touches, alongside specification, enclosure, layout, user-interface design and environmental testing, and a one-person design role is the fastest way to acquire it.[302][138] For an electronics job application, bringing source code for personal projects is concrete evidence in a way a resume line is not.[27] Under the open-source hardware definition, the release must include the firmware needed to make the hardware work, not just schematics and Gerbers — hence the proposal for a badge whose letters mark which of schematic, PCB, firmware, mechanical CAD and documentation have actually been released.[195][921]

Design choices reduce firmware work. USB Power Delivery negotiation once had to be written from scratch; single-chip solutions now arrive pre-programmed and pin-strapped for the desired power level, which is a reason to avoid multiple isolated processors in a redesign.[1561] Conversely, some capabilities cannot be moved into firmware at all: sample compression in a logic analyser requires the hardware capability to exist, normally in an FPGA.[290]

## Manufacturing and provenance

Programmed parts create supply-chain failure modes. Chips arriving on the reel pre-programmed with another company's firmware — in one case an unidentified Motorola image — point either to grey-market parts recovered and re-reeled, or to a manufacturer's own mis-programmed stock being returned to inventory and sold.[134] Production programming is visible on the board itself: a marker cross on a flash device is an operator's record that the part has been programmed.[800] Kits and modules commonly ship pre-flashed, with the customisation done from a desktop application rather than a toolchain.[464]

Firmware version mismatch is a hazard in multi-node systems. Battery modules bought at different times carried different firmware, and without a gateway to update them, the mismatch was the suspected cause of one module repeatedly shutting itself down safely.[aANZNwmnC_4] Legacy equipment shows the opposite problem: a note acceptor with 2002-vintage firmware cannot recognise a banknote series introduced in 2006, and reflashing requires pulling the parallel flash and programming it externally.[525][526] As a general bench practice, checking for and applying available firmware on any acquired equipment is worth doing as a matter of course.[1615]
